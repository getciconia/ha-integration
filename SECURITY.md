# Security

Please don't report security problems in public issues.

Use **Report a vulnerability** on this repository's
[Security tab](https://github.com/getciconia/ha-integration/security) instead,
with what you found and how to reproduce it. Only the maintainers see it.

Things we especially want to hear about: the integration leaking an access
token or positions (in logs, diagnostics or entity attributes), or accepting
data it shouldn't.
